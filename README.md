# huslayer826/tap

Homebrew tap for [Bubble Harness](https://github.com/huslayer826/bubble-harness).

```sh
brew install --cask huslayer826/tap/bubble-harness
```

Update with `brew upgrade --cask bubble-harness`. Remove with `brew uninstall --cask bubble-harness` (add `--zap` to also delete chats and settings).
